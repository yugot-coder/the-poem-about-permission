# the-poem-about-permission — The Poem About Permission

A short poem about agency: the power to ask and to be given. A person
lends their name — and with it, their hands — to an agent that acts for
them; the agent signs where they would sign, knocks where they would
knock, then gives the name back at dusk. Nothing of the lender is
missing: handing over the power to act does not spend it.
